# Video notebook interface (adapters + tool modules)

The video LoRA notebook `notebooks/lora_training_video.ipynb` is generated by `build_video_notebook.py`.
It embeds these modules with `%%writefile` and imports them:

- `video_adapters/<family>.py` → written to `lora_video_adapters/<family>.py` (one per model family)
- `video_adapters/wan_common.py` → `lora_video_tools/wan_common.py` (shared Wan code, imported by every adapter)
- `video_tools/video_io.py`, `video_tools/video_metrics.py`, `video_tools/remedy.py` → `lora_video_tools/*.py`

Pinned stack: Python 3.14, torch 2.15.0, diffusers 0.42.1, peft 0.21.2, transformers 5.22.1, accelerate 1.15.0,
av (PyAV, decoder/encoder), ftfy (diffusers' Wan prompt cleaning), numpy, pillow, pandas, matplotlib.
Optional: onnxruntime (CCIP identity metric).
No torchvision (no torch 2.15 build exists).

Families (all Wan architecture, Apache-2.0):

| family | model to train (diffusers repo) | denoisers | conditioning |
|---|---|---|---|
| `wan22_t2v` | Wan-AI/Wan2.2-T2V-A14B-Diffusers | `transformer` (high noise), `transformer_2` (low noise), boundary 0.875 | text only; images (F=1) and clips |
| `wan22_i2v` | Wan-AI/Wan2.2-I2V-A14B-Diffusers (also AniSora V3.2 after conversion) | same, boundary 0.9 | first frame: 36 = 16 noisy + 4 mask + 16 latent of [frame0, zeros]; clips only |
| `wan22_ti2v_5b` | Wan-AI/Wan2.2-TI2V-5B-Diffusers | `transformer` | images: T2V mode; clips: T2V or I2V mode (clean first latent frame, per-token timestep 0 there, loss excludes it) |
| `wan21` | Wan-AI/Wan2.1-T2V-1.3B-Diffusers or Wan2.1-T2V-14B-Diffusers | `transformer` | text only |

The notebook picks the family itself from `MODEL_PATH` (cell 0-2 `detect_family`, config JSON only): model_index
`_class_name`, two experts (`transformer_2` + `boundary_ratio`), transformer `in_channels`, VAE `z_dim`,
`expand_timesteps` and `image_encoder`. The adapter's `load_pipeline` repeats the full `check_variant` on the real
folder. When adding a family, extend both and run `test_video_user.py` (user mode: only TRIGGER, MODEL_PATH,
RUN_NAME, DATASET_DIR, TARGET_SCOPE are given).

## Adapter module (`video_adapters/<family>.py`)

```python
FAMILY: str
PIPELINE_CLASS: type                 # WanPipeline or WanImageToVideoPipeline (used for from_pretrained and type check)
EXPERTS: list[str]                   # pipeline attribute names of trainable denoisers, high-noise expert first
EXPERT_TAGS: dict[str, str]          # {"transformer": "high", "transformer_2": "low"} or {"transformer": "main"}
CONDITIONING: str                    # "t2v" | "i2v_concat" | "ti2v"
FPS: int                             # 16 (A14B, 2.1) or 24 (TI2V-5B): training clips are resampled to this
SPATIAL_FACTOR: int                  # VAE spatial downsample: 8, or 16 for TI2V-5B
SPATIAL_MULTIPLE: int                # pixel H and W must be multiples of this: 16, or 32 for TI2V-5B
TEMPORAL_FACTOR: int                 # 4 -> frame count must be 4k+1; latent frames = 1 + (F-1)//4
TOKEN_DIV: int                       # tokens per latent frame = (H/TOKEN_DIV)*(W/TOKEN_DIV): 16, or 32 for TI2V-5B
VAL_STEPS: int                       # official sampling steps (I2V-A14B 40, T2V-A14B 40, TI2V-5B 50, Wan2.1 50)
VAL_SHIFT: float                     # official flow shift (I2V-A14B 5.0, T2V-A14B 12.0, TI2V-5B 5.0, Wan2.1 per official config)
VAL_GUIDANCE: tuple[float, float]    # (high-noise expert, low-noise expert); single-expert families repeat the value
NEGATIVE_PROMPT: str                 # official Wan sample_neg_prompt (wan/configs/shared_config.py), verbatim
LORA_TARGETS: dict[str, list[str]]   # scope -> peft target_modules suffixes, block linears only:
                                     #   "all":  attn1/attn2 .to_q .to_k .to_v .to_out.0 + ffn.net.0.proj + ffn.net.2
                                     #   "attn": the 8 attention projections
                                     #   "kvo":  attn1/attn2 .to_k .to_v .to_out.0 (motion-preserving option)

def sigma_range(pipe, expert: str) -> tuple[float, float]
    # training sigma range of an expert. A14B: high = [boundary, 1.0], low = [0.0, boundary) with
    # boundary = pipe.config.boundary_ratio (the pipeline uses the high expert when t >= boundary*1000, t = 1000*sigma).
    # Single-expert families: (0.0, 1.0).
def load_pipeline(model_path: str, dtype) -> pipeline
    # from_pretrained; must raise a clear ValueError when the folder is the wrong variant
    # (e.g. boundary_ratio missing for A14B, transformer in_channels 16 vs 36 for T2V vs I2V, VAE z_dim 48 vs 16).
def tiny_pipeline(dtype) -> pipeline
    # random tiny components with the SAME classes as the real model (configs from diffusers v0.42.1
    # tests/pipelines/wan/test_wan*.py); text encoder from hf-internal-testing/tiny-random-t5 (eval mode).
def encode_prompts(pipe, prompts: list[str], device, dtype) -> list[dict]
    # one dict per prompt: {"prompt_embeds": (1, 512, D) tensor on CPU}; UMT5 with max_sequence_length=512
    # (pipeline.encode_prompt defaults to 226 - pass 512), positions after the real length are zeros.
    # Requires ftfy: raises ImportError naming `pip install ftfy` when diffusers reports it unavailable.
def encode_video(pipe, frames, device, dtype, condition: bool) -> dict
    # frames: np.uint8 (F, H, W, 3), F = 4k+1 (F=1 for images), H and W multiples of SPATIAL_MULTIPLE.
    # returns {"x0": (1, C, f, h, w) float32 CPU} = (posterior mode - latents_mean) / latents_std.
    # CONDITIONING == "i2v_concat" and condition=True: also {"cond": (1, 4 + C, f, h, w) float32 CPU}
    #   = cat([mask4, normalized latent of cat([frame0, zeros(F-1)])]) exactly as WanImageToVideoPipeline.prepare_latents.
def forward_loss(pipe, denoiser, x0, cond, text, noise, sigma, mode: str) -> torch.Tensor
    # x0, noise: (1, C, f, h, w) on device; sigma: (1,) in (0,1); text: encode_prompts dict moved to device;
    # cond: encode_video dict moved to device (or None). mode: "t2v" or "i2v".
    # Flow matching: x_t = (1 - s) x0 + s noise, target = noise - x0, transformer timestep = 1000 * s as float.
    # "i2v_concat": hidden_states = cat([x_t, cond["cond"]], 1) (mode must be "i2v").
    # "ti2v" + mode "i2v": first latent frame replaced by clean x0[:, :, :1], per-token timestep 0 on its tokens and
    #   1000*s elsewhere (as the pipeline's expand_timesteps path), loss over latent frames 1: only.
    # "ti2v" + mode "t2v": all tokens get timestep 1000*s (expand_timesteps layout), loss over all frames.
    # Calls the denoiser exactly once. Casts inputs to the denoiser dtype; returns fp32 scalar MSE.
def lora_to_comfy(peft_state_dict: dict) -> dict
    # peft names ("blocks.0.attn1.to_q.lora_A.weight", optional "transformer." prefix) ->
    # ComfyUI/original Wan names "diffusion_model.blocks.0.self_attn.q.lora_A.weight":
    #   attn1.to_q/k/v/out.0 -> self_attn.q/k/v/o, attn2.* -> cross_attn.*, ffn.net.0.proj -> ffn.0, ffn.net.2 -> ffn.2.
    # Raises on any key it cannot map. No alpha keys (alpha == rank, ComfyUI scale 1).
def save_lora(peft_state_dict: dict, path: str, metadata: dict[str, str]) -> str
    # writes lora_to_comfy(...) as fp32 contiguous safetensors with metadata; returns path.
def load_lora(pipe, path: str, expert: str, adapter_name: str) -> None
    # pipe.load_lora_weights(path, adapter_name=..., load_into_transformer_2=(expert == "transformer_2")), then writes
    # the file's exact fp32 values back into the new adapter (peft casts it to the bf16 base dtype), so a reload is
    # bit-exact against the trained fp32 LoRA (the notebook asserts < 1e-6). ValueError if the pipeline has no such
    # expert or an adapter parameter has no value in the file.
def generate(pipe, text: dict, negative: dict, *, height: int, width: int, num_frames: int, generator,
             image=None, steps: int | None = None, shift: float | None = None,
             guidance: tuple[float, float] | None = None, device=None, offload: bool = False) -> np.ndarray
    # returns uint8 (T, H, W, 3). Uses cached embeddings (prompt_embeds / negative_prompt_embeds).
    # Temporarily sets the UniPC flow_shift to `shift` (default VAL_SHIFT; the A14B / Wan2.1 -Diffusers repos ship 3.0, TI2V-5B 5.0) and
    # restores the scheduler. A14B: guidance_scale = guidance[0] (high), guidance_scale_2 = guidance[1] (low).
    # image (PIL) is required for "i2v_concat" and optional for "ti2v" (then I2V generation).
    # offload=True on CUDA: diffusers model CPU offload for the call, hooks removed afterwards
    # (the notebook re-places modules after generate()). On CPU: plain call.
    # device=None: cuda when offload=True and CUDA is available, else pipe._execution_device.
```

Device contract (as in the image notebook): training puts only the active expert on the device (bf16 weights,
fp32 LoRA params); text encoder and VAE live on CPU and are moved to the device only while encoding/decoding.

## `video_tools/video_io.py`

```python
IMG_EXT: set[str]; VID_EXT: set[str]
STATIC_MOTION = 0.05; CAMERA_MOVING = 0.10   # motion thresholds, unit = fraction of the frame's long side per second
def is_animated_image(path) -> bool  # animated GIF / APNG / WebP by content (not extension); multi-page TIFF, MPO and
                                 # 1-frame files are False. The notebook sends image-extension files with True to the clip
                                 # path; probe/read_frames also read them as clips on their own.
def probe(path) -> dict          # PyAV packet-PTS scan: kind ("image" | "video"), frames, fps, duration, vfr, rotation,
                                 # width, height (display), codec, pix_fmt, header_frames, avg_rate, has_alpha, hdr.
                                 # frames = decodable frames: packets outside an mp4/mov edit list (pkt.is_discard, e.g.
                                 # `ffmpeg -ss X -c copy` trims) are not counted. Animated images -> kind "video".
                                 # VP8/VP9 webm with alpha_mode=1 -> has_alpha True, pix_fmt "yuva420p".
                                 # Still images: rotation = EXIF rotation part (orientations 2/4/5/7 also mirror).
def read_frames(path, max_side=None) -> tuple[np.ndarray, np.ndarray]   # (T,H,W,3) uint8, timestamps (T,) seconds;
                                 # rotation and SAR applied, alpha flattened on white, optional downscale for analysis.
                                 # VP8/VP9 alpha webm is decoded with libvpx (FFmpeg's native vp8/vp9 drop alpha); without
                                 # libvpx it warns and returns the frames without alpha.
def load_image(path) -> np.ndarray   # (H,W,3) uint8; EXIF transpose, 16-bit/float to 8-bit, alpha on white
def frame_signals(frames, fps, analysis_side=96) -> dict   # per frame: mean_luma, black, blur, sat, rgb; per transition:
                                 # mad (neighbour), mad_ref (vs first frame of the still run, as ffmpeg freezedetect),
                                 # content, hist_corr, motion_med/p95 at 1 frame, motion_*_s at motion_s ~ 1/16 s,
                                 # motion_*_k at motion_k ~ 0.5 s
def detect_events(sig, fps, min_scene_s=0.5, freeze_min_s=0.25, timestamps=None) -> dict
                                 # cuts, black, freeze, hold_ratio, drawing_fps. freeze uses mad_ref (slow motion
                                 # accumulates and is not a freeze); hold_ratio uses neighbour mad. With timestamps
                                 # (from read_frames) a still picture is measured by display time rounded to frames, so a
                                 # VFR/GIF frame shown >= round(freeze_min_s*fps)+1 frame durations is a freeze (the CFR
                                 # rule); CFR timestamps give the same result as no timestamps.
def clean_segments(n_frames, events) -> list[tuple[int, int]]          # half-open, no cut/black/freeze inside
def summarize_clip(frames, fps, sig=None, events=None, timestamps=None) -> dict   # subject_motion, camera_motion
                                 # (fraction of the long side per second, max over the 1-frame / ~1/16 s / ~0.5 s
                                 # comparisons), static, hold_ratio, drawing_fps, blur, n_cuts, n_black, n_freeze, sat,
                                 # mean_rgb. Accepts one frame (images: blur and sat; motion 0, hold_ratio nan).
def clip_signature(frames, k=8, skip_first=False) -> np.ndarray; def signature_distance(a, b) -> float
def caption_issues(caption, trigger_re, is_clip, fixed_words=(), summary=None) -> list[str]
                                 # motion = dynamic verb forms only (standing, holding, pointed, closed, close-up are not
                                 # motion); camera/shot = static/locked-off camera, "the camera slowly pans", close-up /
                                 # closeup / close up, long shot, full body ...; English and common Korean expressions
def resample_to_fps(timestamps, target_fps) -> np.ndarray               # index of the frame on screen at each grid time
                                 # k/target_fps, identical to ffmpeg's fps filter (round=near, ties up, so 32 -> 16 fps
                                 # keeps frames 0, 2, 4, ...); length = round((last + median dt) * target_fps)
def round_4k1(n, temporal=4) -> int
def windows(seg_len, F, mode="uniform", n=3, rng=None) -> list[int]
def make_buckets(token_budget, frame_options, aspects, max_area, token_div, temporal, multiple) -> list[tuple]
def pick_bucket(buckets, avail_frames, w, h, prefer="frames", allow_upscale=1.0) -> tuple | None   # (F, H, W, tokens)
def resize_crop_frames(frames, h, w) -> np.ndarray                      # one scale + center crop for all frames
def contact_sheet(rows, labels=None, n=8, thumb_h=120, pad=4) -> PIL.Image
def save_mp4(path, frames, fps, crf=18) -> str; def save_webp(path, frames, fps) -> str
def make_test_dataset(root, trigger) -> dict                            # synthetic images + clips with known problems
                                 # (incl. edit-list trim, VP9 alpha webm, animated WebP, VFR long hold), returns
                                 # expectations for TEST-mode asserts
def check_test_expectations(df, events, dup_pairs, exp) -> None         # TEST mode: notebook EDA table vs expectations;
                                 # df rows of animated images must be kind "video"; events from detect_events(..., timestamps=ts)
```

## `video_tools/video_metrics.py`

```python
MOTION_SIDE = 224; MOTION_FLOOR = 1.0; FLICKER_FLOOR = 1.0; CONTRAST_REF = 60.0; CONTRAST_GMAX = 4.0
def motion_amount(frames) -> float   # mean |frame difference| of 64 px luma (0-1), reference only (flicker raises it)
def block_motion_p95(frames, side=MOTION_SIDE) -> float   # px/frame at the clip's own size: 8x8 block matching +
                                 # sub-pixel Lucas-Kanade on luma downscaled to `side` (MOTION_RESAMPLE = LANCZOS,
                                 # antialiased), mean over transitions of the top-5% block displacement. A dark or
                                 # low-contrast clip is first multiplied by a clip contrast gain (CONTRAST_REF / contrast,
                                 # 1 to CONTRAST_GMAX). A transition whose frame std ratio (next / previous) is outside
                                 # GAIN_RANGE = (0.6, 1.6) (black or white frames, fade ends) is left out of the mean;
                                 # if none is left (strong frame-to-frame flicker, every other frame black), same-phase
                                 # frames two apart (t, t+2) whose std ratio is inside GAIN_RANGE are compared (displacement
                                 # / 2, larger of the even/odd phase means). When the gain is above 1, per transition the
                                 # block threshold tau and displacement penalty lam rise with the gained temporal noise of
                                 # flat blocks (capped at the ungained 2 and 1; the noise is also measured after a global
                                 # integer shift + per-block LK and the smaller value is used, so texture motion is not
                                 # taken for noise), so the gain does not turn smooth noise in dark clips into motion.
def flicker(frames) -> dict          # flicker_ratio, luma_flicker (high-pass RMS of per-frame mean luma, 0-255)
def contrast_flicker(frames) -> float   # high-pass RMS of per-frame luma std (0-255), the 2 largest squared samples
                                 # dropped (a scene cut is one step = 2 samples); no trim below 3 samples, 0.0 below 3 frames.
                                 # A 2-4 frame dissolve or two cuts can still count as contrast flicker.
def color_stats(frames) -> dict      # r, g, b, sat, val
class Dino: load(device) -> Dino | None; embed(frames) -> np.ndarray      # optional (facebook/dinov2-small, letterbox)
def subject_consistency(E) -> float; def style_drift(E_a, E_b) -> float
class CCIP: load() -> CCIP | None; features(images); identity(frames, ref_feats) -> dict   # optional (onnxruntime)
def clip_metrics(frames, base=None, dino=None, ccip=None, ref_feats=None) -> dict
    # keys: motion, motion_ratio, luma_flicker, contrast_flicker, flicker_rel, flicker_ratio, sat, color_shift,
    # consistency, drift, id_pass, id_mean, id_slope. Not measured -> None; empty frames -> motion 0.0, all else None.
    # motion_ratio = motion / base motion (None when base motion < MOTION_FLOOR px/frame).
    # flicker_rel = max(luma_flicker / max(base luma_flicker, FLICKER_FLOOR),
    #                   contrast_flicker / max(base contrast_flicker, FLICKER_FLOOR))   (remedy flags > 1.5)
    # luma_flicker and contrast_flicker are the clip's own values, so a table shows which one flickered.
```

## `video_tools/remedy.py`

```python

    # later steps, so a tie picks the pair where both experts are trained; diagnose names the step where it was measured)
    # after = last step of the first expert (A14B, else None): with id_pass measured, the earliest identity+quality pass
    # after it comes first (the low-noise expert learns identity first, so otherwise the high-noise LoRA is never picked).
    # The notebook passes id_pass=None for I2V (the preview starts from a training picture, so the base passes CCIP too)

def next_run_name(name: str) -> str
def next_run_plan(user: dict, overrides: dict, changes: list[dict], best_step, base_overrides=None) -> dict

    # output_dir, validation_file (absolute), trigger, run_name (version bumped, zero padding kept), expert, class_word,
    # target_scope, caption_fixed_words, fixed_overrides = {**base_overrides, **overrides} (alpha = rank), why, previous.
    # val_loss=None in diagnose / pick_best_step: loss evidence is ignored (validation loss not on held-out files).
```
